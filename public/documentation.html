Getting Started

MelonRPC is a standard Solana JSON-RPC endpoint. Replace your existing RPC URL with https://melonrpc.click and you're live. Compatible with all major SDKs including @solana/web3.js, Anchor, and solana-py.

No API key required during beta â€” just swap the URL and start building.

Quick Start

// JavaScript / TypeScript
import { Connection } from '@solana/web3.js'

const connection = new Connection('https://melonrpc.click', {
  wsEndpoint: 'wss://melonrpc.click',
  commitment: 'confirmed'
})

const balance = await connection.getBalance(publicKey)
# cURL
curl https://melonrpc.click -X POST \
  -H "Content-Type: application/json" \
  -d '{"jsonrpc":"2.0","id":1,"method":"getSlot"}'

MelonRPC supports all standard Solana JSON-RPC methods. Requests are standard POST with Content-Type: application/json. Batch requests are also supported.

getBalance

Returns the lamport balance of the account at the given public key.

Request

{
  "jsonrpc": "2.0",
  "id": 1,
  "method": "getBalance",
  "params": ["vines1vzrYbzLMRdu58ou5XTby4qAqVRLmqo36NKPTg"]
}

Response

{
  "jsonrpc": "2.0",
  "id": 1,
  "result": {
    "context": { "slot": 123456789 },
    "value": 1000000000
  }
}

getAccountInfo

Returns all account information for the given public key, including lamports, owner, data, and executable status.

Request

{
  "jsonrpc": "2.0",
  "id": 1,
  "method": "getAccountInfo",
  "params": [
    "vines1vzrYbzLMRdu58ou5XTby4qAqVRLmqo36NKPTg",
    { "encoding": "base64" }
  ]
}

Response

{
  "jsonrpc": "2.0",
  "id": 1,
  "result": {
    "context": { "slot": 123456789 },
    "value": {
      "data": ["", "base64"],
      "executable": false,
      "lamports": 1000000000,
      "owner": "11111111111111111111111111111111",
      "rentEpoch": 350
    }
  }
}

getSlot

Returns the slot that has reached the given or default commitment level.

Request

{
  "jsonrpc": "2.0",
  "id": 1,
  "method": "getSlot"
}

Response

{
  "jsonrpc": "2.0",
  "id": 1,
  "result": 286413215
}

getBlockHeight

Returns the current block height of the node.

Request

{
  "jsonrpc": "2.0",
  "id": 1,
  "method": "getBlockHeight"
}

Response

{
  "jsonrpc": "2.0",
  "id": 1,
  "result": 263850012
}

getTokenAccountsByOwner

Returns all SPL token accounts for a given owner public key, filtered by mint or program ID.

Request

{
  "jsonrpc": "2.0",
  "id": 1,
  "method": "getTokenAccountsByOwner",
  "params": [
    "vines1vzrYbzLMRdu58ou5XTby4qAqVRLmqo36NKPTg",
    { "programId": "TokenkegQfeZyiNwAJbNbGKPFXCWuBvf9Ss623VQ5DA" },
    { "encoding": "jsonParsed" }
  ]
}

Response

{
  "jsonrpc": "2.0",
  "id": 1,
  "result": {
    "context": { "slot": 123456789 },
    "value": [
      {
        "pubkey": "...",
        "account": { "lamports": 2039280, "data": { ... } }
      }
    ]
  }
}

getSignaturesForAddress

Returns confirmed signatures for transactions involving an address. Returns newest first, paginated by before/until signatures.

Request

{
  "jsonrpc": "2.0",
  "id": 1,
  "method": "getSignaturesForAddress",
  "params": [
    "vines1vzrYbzLMRdu58ou5XTby4qAqVRLmqo36NKPTg",
    { "limit": 5 }
  ]
}

Response

{
  "jsonrpc": "2.0",
  "id": 1,
  "result": [
    {
      "signature": "5K4s...",
      "slot": 286413000,
      "err": null,
      "blockTime": 1700000000
    }
  ]
}

sendTransactionwrite

Submits a signed transaction to the cluster for processing. The transaction must be fully signed and serialized (base64 or base58).

Request

{
  "jsonrpc": "2.0",
  "id": 1,
  "method": "sendTransaction",
  "params": [
    "<base64-encoded-transaction>",
    { "encoding": "base64" }
  ]
}

Response

{
  "jsonrpc": "2.0",
  "id": 1,
  "result": "2id3YC2jK9G5Wo2phDx4gJVAew8DcY5NAojnVuao8rkxwPYPe8..."
}

accountSubscribewebsocket

Subscribe to an account to receive notifications when the account's lamports or data changes. Connect via wss://melonrpc.click.

Standard WebSocket subscriptions are available on the free tier. Enhanced WebSocket methods require the Growth plan ($49/mo).

Subscribe

{
  "jsonrpc": "2.0",
  "id": 1,
  "method": "accountSubscribe",
  "params": [
    "vines1vzrYbzLMRdu58ou5XTby4qAqVRLmqo36NKPTg",
    { "encoding": "base64", "commitment": "confirmed" }
  ]
}

Notification

{
  "jsonrpc": "2.0",
  "method": "accountNotification",
  "params": {
    "subscription": 1,
    "result": {
      "context": { "slot": 286413300 },
      "value": { "lamports": 500000000, "data": ["", "base64"] }
    }
  }
}

slotSubscribewebsocket

Subscribe to receive notification any time a slot is processed by the validator.

Subscribe

{
  "jsonrpc": "2.0",
  "id": 1,
  "method": "slotSubscribe"
}

Notification

{
  "jsonrpc": "2.0",
  "method": "slotNotification",
  "params": {
    "subscription": 0,
    "result": { "slot": 286413400, "parent": 286413399, "root": 286413370 }
  }
}

Error Codes

MelonRPC returns standard JSON-RPC error codes. All errors follow this shape:

{
  "jsonrpc": "2.0",
  "id": 1,
  "error": {
    "code": -32600,
    "message": "Invalid request"
  }
}
-32700 â€” Parse Error

Invalid JSON was received.

-32600 â€” Invalid Request

The JSON sent is not a valid JSON-RPC request.

-32601 â€” Method Not Found / Not Allowed

The method does not exist or is not in the allowlist.

-32602 â€” Invalid Params

Invalid method parameters.

-32603 â€” Internal Error

Internal JSON-RPC error.

-32000 â€” Rate Limited

Too many requests from your IP. Wait and retry.

429 â€” HTTP Too Many Requests

Monthly credit limit exceeded. Upgrade to increase your allocation.
